A comprehensive enterprise-grade platform designed for streamlined pre-screening, monitoring, and analysis of SME loan applications.
Built for financial institutions, credit teams, and operational analysts, the dashboard offers end-to-end visibility into loan performance, compliance, and workflow stages — helping decision-makers process SME applications faster and more accurately.

🌐 Live Application

Access the deployed production version:

🔗 https://sme-loan-portfolio.vercel.app/login
📌 Overview

The SME Loan Portfolio Dashboard centralizes application insights, workflow tracking, and risk indicators to improve decision-making across loan evaluation processes.

This system replicates a real-world banking dashboard experience with features such as:

Multi-stage screening workflow

Application-level metrics

Industry distribution analytics

Document compliance summaries

Dark/Light mode support

Fully responsive design

The clean UI and optimized data visualization enable teams to quickly understand portfolio health and take action.

🏢 Key Features
1. Pre-Screening Dashboard

A central summary of loan readiness, approvals, rejections, and hold status — complete with trends and indicators.

2. Industry & Category Distribution

Visual breakdown of SME loan applications across sectors like Services, Trading, and Manufacturing.

3. Compliance & Documentation Analysis

Track missing vs. submitted documents for KYC, income proof, and business verification.

4. Loan Amount Distribution

Understand the spread of loan sizes across small, medium, and large enterprises.

5. Real-Time Workflow Tracking

Monitor each application’s progress through KYC, financial checks, and screening outcomes.

6. Dual Theme Support

Switch seamlessly between Dark Mode and Light Mode for optimal usability.

7. Modern & Responsive UI

Designed using enterprise dashboard UX principles for a banking/FinTech environment.

🏗️ Architecture Overview

The platform follows a modular, scalable, component-driven architecture inspired by enterprise dashboards:

Frontend Framework: React (Next.js optional)

UI Framework: Tailwind CSS (or custom design system)

Charts & Visuals: Recharts / Chart.js

API Layer: REST-based API (integrated with backend loan data systems)

State Management: React Context / Hooks

Deployment: Vercel

The design ensures performance, maintainability, and compatibility with enterprise authentication systems and banking workflows.
